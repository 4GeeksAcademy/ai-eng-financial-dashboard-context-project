# Product Overview

## What This Project Does

The Financial Dashboard is a web application that displays financial information, including income, expenses (outcomes), profit metrics, and charts.

## How It Works

1. The React frontend requests financial data from the FastAPI backend using `/api/metrics`.
2. The backend returns generated mock financial transactions.
3. The frontend calculates KPIs and monthly financial summaries.
4. Dashboard components display the results in cards and charts.

## Key Features

- Income, outcome, and profit metrics
- Financial charts and monthly summaries
- Backend API endpoints for filtering, comparisons, categories, and alerts
- Loading and error handling in the frontend

## Verified Evidence

- `frontend/src/App.tsx` — Fetches financial data and renders the dashboard.
- `frontend/src/lib/financial-utils.ts` — Calculates KPIs and monthly data.
- `frontend/src/components/dashboard/` — Contains dashboard components.
- `backend/app/routes.py` — Defines financial API endpoints and mock data generation.
- `PHASE1-VERIFICATION.md` — Documents source inspection and successful runtime checks.

## Data Source

The project currently uses reproducible mock financial transactions generated by the backend. A live financial database was not established during verification.
