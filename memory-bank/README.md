# Memory bank

Memoria del proyecto para el siguiente contribuidor o agente. **Verificado contra el commit `c06ab07`.**

| Archivo | Contenido |
|---|---|
| `product-overview.md` | Qué es el producto, qué muestra, modelo de datos y API. |
| `tech-stack.md` | Lenguajes, frameworks, dependencias, infraestructura y comandos. |
| `current-state.md` | Qué funciona, huecos conocidos y siguientes prioridades. |

## Cómo usarlo y mantenerlo

- Lee estos archivos y `.agents/rules/` antes de cambiar nada (lo pide `AGENTS.md`).
- Leyenda: ✅ comprobado leyendo el código o ejecutándolo · ❓ sin verificar. Las rutas se citan como `ruta` o `ruta:línea`.
- Si un cambio altera algo descrito aquí, actualiza el archivo en el mismo commit y cambia el commit de verificación de arriba.
- No añadas afirmaciones de producto, fechas ni planes que no estén respaldados por un archivo del repositorio.
- Las referencias a funciones valen más que los números de línea, que se desplazan.
