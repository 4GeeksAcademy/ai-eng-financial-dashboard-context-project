## Criterio de evidencia

Las referencias apuntan a código, configuración, pruebas o documentación del repositorio. La inspección de esos archivos es evidencia estática; no demuestra que los servicios o las pruebas se hayan ejecutado correctamente. Cada documento indica expresamente las verificaciones no realizadas.
