_Financial metrics dashboard with a React + TypeScript frontend and a FastAPI backend._

## Overview

This project is a demo dashboard for exploring financial metrics. It displays total income, total expenses, net profit, and profit margin, with monthly charts for income versus expenses and profit margin.

The dashboard uses synthetic data generated by the backend; it is not connected to real financial records and does not persist movements. The current UI does not provide data import, editing, date selection, or filters. Its period label is static and may not match the generated data range.

## Technology stack and architecture

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and Recharts.
- **Backend:** Python 3.13, FastAPI, Uvicorn, and Pydantic.
- **Local environment:** Docker Compose.

The browser loads the React app from Vite. The app requests `GET /api/metrics`; Vite proxies `/api` requests to FastAPI. The backend generates synthetic movements in memory. The frontend calculates KPI totals and monthly chart data.

## Requirements and quick start

Requirements: Docker and Docker Compose.

From the repository root, run:

```bash
docker compose up --build
```

The Vite `/api` proxy is used by default. To target a different backend origin, copy `frontend/.env.example` to `frontend/.env` and set `VITE_API_BASE_URL` there.

- Dashboard: http://localhost:5173
- Backend API: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- OpenAPI schema: http://localhost:8000/openapi.json

## Development and checks

With the Docker Compose services running:

```bash
docker compose exec backend pytest

```

## API

All metrics endpoints return synthetic data. The dashboard currently consumes only `GET /api/metrics`.

| Method and route | Purpose |
|---|---|
| `GET /health` | Health check |
| `GET /api/metrics` | List movements; supports date, category, and operation filters |
| `GET /api/metrics/facets` | Return available filter values and date bounds |
| `GET /api/metrics/summary` | Aggregate income, expenses, and net by day, week, or month |
| `GET /api/metrics/categories/top` | Rank categories by total amount |
| `GET /api/metrics/comparison` | Compare net values across adjacent date ranges |
| `GET /api/metrics/alerts` | Identify periods with increased expenses |
| `GET /api/metrics/b2b` | List B2B movements |
| `GET /api/metrics/b2c` | List B2C movements |

Use Swagger UI at `/docs` to inspect request parameters and response schemas.
