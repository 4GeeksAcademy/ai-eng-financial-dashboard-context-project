# M2: Guardar instrucciones de agentes bajo `.agents/rules/`

**Alcance:** Creación o actualización de reglas para agentes y contribuidores en este repositorio.

**Justificación:** `AGENTS.md` exige revisar `./.agents/rules`, y `README.es.md` documenta `.agents/rules/<nombre-regla>.md` como ubicación esperada.

**Guía accionable:**
- Guarda cada regla del proyecto como un archivo Markdown dentro de `.agents/rules/`.
- Usa nombres de archivo descriptivos y conserva en cada regla un alcance comprobable y hechos del repositorio que la motivan.
- No sustituyas `.agents/rules/` por `.agent/rules`; la ruta singular no es la que declaran `AGENTS.md` y el README.
