# Agent Guidance

Agents working on this project **must**:

- Read the validated project rules in `./.agents/rules.md` before analyzing or modifying the backend or frontend.

- Look for available **agent skills** in the directory:  
  `./.agents/skills`

- Look for the **project memory bank** in:  
  `./memory-bank`  
  _(if the directory exists)_

Before taking action (analyzing code, modifying files, or generating outputs), always review the latest project instructions and memory available in these locations to ensure compliance with project conventions, context, and operational constraints.
