# Architecture Decision Records

This folder is the canonical home for Architecture Decision Records (ADRs). Record a significant decision in its own numbered file using [`0000-template.md`](0000-template.md). ADRs and this index are maintained in English. Do not create retrospective ADRs for choices that have not actually been made. Link related engineering standards, product scope, and verification evidence where useful.

Use a stable status: `Proposed`, `Accepted`, `Rejected`, `Superseded`, or `Deprecated`. When a decision changes, preserve the old record and create a new ADR that supersedes it.
